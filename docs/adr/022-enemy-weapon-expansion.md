# ADR 022 — 敌人角色化与武器扩展架构

> 状态：accepted
> 来源：grill-with-docs 会话，2026-07-25
> 经济数据权威：[ADR 023](023-currency-backpack-system.md)（三级货币体系）

## 上下文

当前项目只有 3 种泛化敌人（近战/远程/飞行）和 2 把枪（blaster/blaster-repeater）。项目上游有同一 Kenney 系列的丰富素材未使用：
- `kenney_blocky-characters_20`（18 个类人角色，与现怪物同骨架/动画）
- `kenney_cube-pets_1.0`（24 个小动物，不同绑定）
- `kenney_blaster-kit_2.1`（40 个武器模型，约 20 把真枪 + 2 种手雷）

丧尸与狂暴丧尸暂不纳入。

## 决策

### 1. 敌人架构：基类 + 可插拔模块

**选择方案：基类 + 可插拔特殊机制模块组合。**

- `monster_base.gd` 保留 FSM + 避障 + 视线 + 跳跃导航 + 动画 + 受击/死亡框架
- 基类新增 4 个模块钩子，在对应时机遍历已挂载模块调用
- 每个特殊机制实现为一个 `EnemyModule` 节点，挂为敌人的子节点
- 新敌人 = 一个 `.tscn`（GLB 模型 + `@export` 参数 + 挂 1–3 个模块），**不写新子类**

#### 钩子定义

```gdscript
# monster_base.gd
var _modules: Array[Node] = []

func _collect_modules():
    for c in get_children():
        if c.has_method("module_setup"):
            c.module_setup(self)
            _modules.append(c)

func _run_module_hook(method: String, args: Array = []) -> void:
    for mod in _modules:
        if mod.has_method(method):
            mod.callv(method, args)

# 调用时机：
# _change_state() 末尾 → on_enter_state(new_state)
# _tick_state() 末尾 → on_tick(delta)
# damage() 减血前 → on_damage(amount)
# destroy() 中 _dead=true 后 → on_death()
```

模块间**不互斥设计**：若两个模块修改同一属性，按 `_modules` 数组顺序后覆盖前。

#### 耐久设计原则

1. **固定消耗**：每次扣扳机 -1（霰弹齐射/双管双发均只扣 1）
2. **高射速需更多耐久**：机枪 280 发只能连续开火 ~22s
3. **爆发型收紧**：狙击 50、重型狙击 35、榴弹 25——每发都有决策压力
4. **耐久 = 决策压力**：低耐久逼迫"现在用还是留给精英"

#### 定价设计原则

武器价格（3–18 金）综合战斗力 + 弹药使用成本 + 稀缺性。弹药便宜的枪定价可激进，弹药贵的枪适当压价。具体价格见 `weapons/*.tres` 的 `weapon_cost` 字段。

#### 商店三区

- **武器区**：随机 3 把（从 15 把池不重复抽），金定价
- **弹药区**：6 种弹药捆，铜币定价（详见 [ADR 023](023-currency-backpack-system.md)）
- **手雷区**：随机 1–2 种，银币定价（EMP 3 银 / 破片 2 银）

商店仍为物理摊位（ADR 013），走近暂停、离开恢复。

---

### 4. RunDirector 数据驱动化

`MONSTER_COST`、`_available_types`、`_reward_for` 等硬编码重构为 `ENEMY_CONFIG` 字典（16 条目），每项含 `cost` / `reward` / `min_wave` / `scene`。新增敌人 = 追加表条目。

---

### 5. 其他决策

- **键位调整**：挣扎 G→H（G 让给手雷）、新增 `throw_grenade`(G) / `drop_weapon`(X)
- **手雷**：独立槽（不占武器 3 槽），最多 5 颗，初始 EMP×1
- **武器槽**：最多 3 把，允许重复，替换时弹药保留
- **武器丢弃/拾取**：X 键丢弃→地面 Area3D→走过有空槽自动捡起（保留当前耐久）
- **击杀奖励**：按怪类型分档，铜币结算（详见 ADR 023）
- **宝箱扩展**：奖励池 +2 项（随机武器、手雷补给）

## 超出范围

- 丧尸、狂暴丧尸（用户排除）
- cube-pets 独立敌种（仅做驯兽师召唤物）
- 武器配件系统（瞄具/消音器，GLB 保留备用）
- 持续射线枪 beam / 榴弹 AOE 实现细节（P4 工单）
