# ADR-001: 弹体为纯视觉装饰，命中判定保持 Hitscan

## 状态

已废弃（被 ADR-002 取代）

## 背景

当前项目使用 RayCast3D（hitscan）进行射击命中判定——从枪口瞬间检测碰撞，无可见弹体。
为了增强射击的视觉反馈，需要添加从枪口飞向目标的弹体（projectile）。

## 决策

弹体仅作为视觉装饰，命中判定仍由 RayCast 完成。弹体在射击时从枪口位置生成，沿 RayCast 方向飞向碰撞点，到达后销毁。

## 理由

- **保持简单**：项目定位为 arcade FPS starter kit，hitscan 的伤害模型已经稳定且易于理解。
- **无穿透/延迟问题**：真实弹道需要处理飞行时间、预判、穿透等复杂度，与当前游戏风格不符。
- **视觉增强即可**：发光胶囊体 + 快速飞行（80-120 m/s）足以提供"看到子弹"的反馈感，不破坏现有射击手感。

## 替代方案

- **真实弹道（弹体承载命中判定）**：更真实，但需要重写伤害系统、处理飞行时间和碰撞检测，复杂度显著增加。被否决。

## 弹体规格

- 形态：发光拉伸胶囊体（CapsuleMesh + emission 材质）
- 实现：独立场景文件 `objects/projectile.tscn`
- 可配置属性：颜色（projectile_color）、大小（projectile_size）、速度（projectile_speed）
- 配置位置：`Weapon` 资源类的新增属性，通过 Inspector 配置
