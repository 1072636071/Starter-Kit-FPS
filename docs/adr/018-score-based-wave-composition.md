# ADR 018: 分数制波次组成 —— 取代固定数量 + 固定比例

> **修订**：本 ADR 的分数预算公式（`60 × 1.2^(N-1)`）仍有效。但 `MONSTER_COST` 硬编码 3 条目已被 [ADR 022](022-enemy-weapon-expansion.md) 的 `ENEMY_CONFIG` 数据驱动 16 角色版取代；类型解锁表亦由 ADR 022 重新定义。

## 决策

波次怪物组成从**固定数量 + 固定比例**改为**分数预算制**：

- 每种怪物类型有**刷出成本（Monster Cost）**：`monster_melee`=5, `monster_ranged`=8, `enemy`=10（与击杀奖励值一致）。
- 每波有**分数预算（Wave Budget）**：`wave_budget(N) = 60 × 1.2^(N-1)`。
- 刷怪时从可用类型中**随机选取**，直到总成本 ≥ 预算（即"接近并大于预算"）。
- 类型**分阶段解锁**保留：1-3 波仅 melee、4-6 波加 ranged、7+ 波加 enemy。

## 背景

原方案（ADR 009 的 Escalation 定义）使用固定公式 `count = 4 + 2×(N-1)` 加固定比例（60/40、50/30/20）决定每波怪物组成。问题是：

1. **数量增长线性**——后期波次缺少"指数爆发"感，肉鸽竞技场期望后期压力陡增。
2. **固定比例僵硬**——每波 melee/ranged/enemy 比例机械固定，缺乏变化，玩家会感到重复。
3. **扩展性差**——未来新增怪物类型时，需重新设计比例表，且旧类型比例需手动调整。

用户提出分数制方案：每种怪物有"分数"（成本），每波有总预算随机凑到接近预算（初始提议 ×1.5 递增，**最终裁定 ×1.2**）。这解决了上述三个问题。

## 替代方案

| 方案 | 描述 | 否决原因 |
|------|------|----------|
| **A. 分数预算制（选中）** | 怪物有成本，波次有预算，随机选取至总成本 ≥ 预算 | 指数增长提供后期爆发；随机组合增加变化；新增类型只需加成本值 |
| B. 固定数量 + 固定比例（原方案） | `4+2×(N-1)` 只，按固定比例分配类型 | 线性增长、比例僵硬、扩展性差 |
| C. 纯随机数量 | 每波数量在区间内随机，类型随机 | 难度波动过大，缺乏"设计感" |
| D. 分数预算 + 背包精确凑 | 用背包算法精确凑到预算不溢出 | 过度工程；每次刷怪 100+ 只时背包 O(n×budget) 不可接受；近似凑到 ≥ 预算在游戏性上无差异 |

## 影响

- **代码**：~~`MONSTER_COST` 常量~~ → 已被 ADR 022 的 `ENEMY_CONFIG` 数据驱动字典取代。`wave_budget()` 纯函数保留。
- **测试**：波次断言从固定数量改为预算约束 + 类型约束。
- **词汇表**：`CONTEXT.md` 的 `Monster Cost`、`Wave Budget`、`Escalation` 术语以 ADR 022 的 16 角色版为准。
