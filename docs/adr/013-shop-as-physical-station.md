# ADR 013: 子弹商店为场景内固定摊位（walk-in 暂停购买）

## 决策

子弹商店是**竞技场中一个固定位置的物理摊位（Shop Station）**，不是 Intermission 菜单。玩家**走入**其触发区域时**整个游戏暂停**（spawn / AI / 输入冻结）并打开购买 UI，离开 / 关闭后恢复。金币消费因此**不限于间歇**，可随时（含波次进行中）走入购买。

升级卡仍按 ADR 011 + 本会话 Q5 为 XP 跨阈值**即时暂停**弹三选一；商店摊位与升级卡是两套**独立的暂停点**。

## 背景

Q5 用户在选定"升级即时暂停 + 商店只在间歇（A）"后进一步明确：商店是场景固定位置，走进去就暂停补弹购买。这把商店从"间歇菜单"改为"物理可交互摊位"，金币消费与间歇解耦。

## 替代方案

| 方案 | 描述 | 状态 |
|------|------|------|
| **物理摊位 walk-in（选中）** | 场景中固定 Station，走入暂停购买 | 用户指定；提供战术安全点，购买不绑间歇 |
| 间歇菜单 | 商店只在 Intermission 作为 UI 出现 | 被用户否决（用户要物理位置） |

## 影响

- 竞技场场景（`main.tscn` 或 arena 场景）新增一个 **Shop Station** 节点：`Area3D` 触发区 + 可视化模型。
- 玩家进入触发区 → 暂停（spawn / AI / 输入冻结）→ 打开买弹 UI（按 `gold_cost_per_bullet` 加 `reserve`）→ 关闭恢复。
- 商店与 Intermission 解耦：Intermission 仅负责"波间无刷怪"的节奏断点；商店是独立的、随时可触发的物理暂停点。
- 金币消费出口仍为商店（ADR 012 的购买语义不变，只是触发位置从菜单改为 walk-in）。
