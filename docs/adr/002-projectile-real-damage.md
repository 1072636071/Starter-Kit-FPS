# ADR-002: 弹体为实体伤害载体，取代 Hitscan

## 状态

已接受（取代 ADR-001）

## 背景

ADR-001 决定弹体仅为视觉装饰，命中判定保持 RayCast hitscan。
实际体验后认为纯视觉弹体缺乏游戏性——无法预判、无法躲避、无战术深度。
决定改为实体弹体承载真实伤害判定。

## 决策

- 弹体为实体对象（Area3D + CollisionShape3D），飞行中碰撞到物体时造成伤害并销毁
- 完全移除玩家射击的 RayCast 伤害逻辑，弹体为唯一伤害来源
- 敌人射击也改为发射弹体，玩家可通过移动躲避
- 弹体飞行速度 30-50 m/s（中速，需要轻微预判）
- 命中即销毁（不穿透），碰撞点生成 impact 特效
- `weapon.spread` 控制弹体发射方向的随机偏移
- `weapon.max_distance` 控制弹体最大飞行距离

## 理由

- **游戏性提升**：慢速弹体引入预判和躲避机制，增加战术维度
- **体验一致性**：玩家和敌人都使用弹体，对称且公平
- **视觉反馈强**：弹体飞行轨迹清晰可见，命中感更强
- **arcade 风格兼容**：30-50 m/s 不需要太多预判，仍有 arcade 的爽快感

## 被取代的决策

ADR-001（弹体纯视觉装饰）被本决策取代。原因：纯视觉弹体无法提供真实的游戏交互反馈。
