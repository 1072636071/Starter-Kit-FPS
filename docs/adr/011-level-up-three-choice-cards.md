# ADR 011: 升级采用"三选一升级卡"模型

## 决策

经验（XP）累积跨越阈值触发 **Level Up**；每次升级从**升级池（Upgrade Pool）**中随机抽取 **3 个不重复增益**呈现给玩家，**选 1 个**立即生效。增益为对玩家现有属性的**本局内永久**修改，靠随机堆叠形成 build。

## 背景

用户定义核心循环"经验用来获得升级"，但未定义升级产出形态。需决定升级给什么。

## 替代方案

| 方案 | 描述 | 否决原因 |
|------|------|----------|
| **A. 三选一升级卡（选中）** | 每次升级从池中随机抽 3 个增益，玩家选 1 | 肉鸽核心爽点（build 构筑）；最贴合"经验获得升级"的开放表述 |
| B. 固定线性成长 | 每级固定加一点属性（如 +5 血、+2 伤害） | 无选择、无 build 乐趣，平 |
| C. 升级解锁 / 轮换武器 | 经验攒满解锁新武器进武器库 | 与"金币买子弹"资源语义冲突（武器变成第三套资源，越界） |

## 影响

- 需要 **Upgrade Pool**：增益定义集合，每项含 `id` / 描述 / 生效参数（作用于 `health`、`shield`、`damage`、`move_speed`、`reload`、`reserve` 等现有属性）。
- 需要 **Level Up 流程**：XP 跨阈值 → 暂停 → 抽 3（不重复）→ 玩家选 1 → apply → 继续。
- 所有增益**本局内有效**，玩家死亡（本局结束）后随状态一并重置。
- 初版升级池（具体项与数值待后续 grill 细化）：`+20 最大血量`、`+5 护盾恢复速率`、`+15% 伤害`、`+0.5 移动速度`、`+1 每把枪备弹上限`、`-10% 换弹时间`。
- 升级触发时机（达到阈值即时暂停弹卡 / 延迟到 Intermission 统一弹）见后续决策。
