# ADR 023: 三级货币 + 背包弹药系统

**日期**: 2026-07-25
**状态**: accepted

## 背景

当前经济系统仅有金币（Gold）一种货币，弹药按捆在商店购买（如手枪弹捆 24 发/1 金）。这导致两个问题：
1. 子弹感觉昂贵——1 金买 24 发，玩家惜弹如金，不敢随意开火
2. 价格粒度不足——最低消费就是 1 金，无法差异化定价单发子弹

同时，现有备弹池（`ammo_reserve`）容量有限且无重量约束，弹药管理维度单一。

## 决策

### 1. 三级货币体系

引入银币（Silver）和铜币（Copper），汇率：

```
1 金 = 100 银 = 10000 铜
1 银 = 100 铜
```

**定价分层：**

| 物品层级 | 货币 | 示例 |
|---------|------|------|
| 弹药（消耗品） | 铜币 | 单发手枪弹 = 1 铜 |
| 手雷 | 银币 | 破片 = 2 银, EMP = 3 银 |
| 武器 | 金币 | 手枪 3 金, 重型武器 ≤18 金 |

**弹药捆新定价：**

| 弹种 | 捆量 | 新价（铜） | 旧价（金） |
|------|------|----------|-----------|
| 手枪弹 | 24 | 24 | 1 |
| 步枪弹 | 20 | 60 | 2 |
| 霰弹 | 8 | 80 | 3 |
| 狙击弹 | 4 | 80 | 4 |
| 能量电池 | 12 | 60 | 3 |
| 榴弹 | 2 | 100 | 5 |

**击杀奖励**（原金币 ×100 转铜）：近战 500 铜、远程 800 铜、飞行 1000 铜。

UI 显示自动进位：12345 铜 → "1金 23银 45铜"。

### 2. 三层弹药架构

```
背包（重量制，容量大）
  │
  │ T键：打开背包UI → 拖拽分配 → 关UI后1.5s整理动画
  │ （可移动，不可射击）
  ▼
身上备弹槽（10个，每槽=一弹匣量，可自由分配弹种）
  │
  │ R键：正常换弹（现有reload_time速度）
  ▼
弹匣（武器内，开火消耗）
```

### 3. 背包系统

**负重制**：无格子上限，仅有重量上限（初始 80）。

| 物品 | 重量/单位 |
|------|----------|
| 手枪弹 | 0.01/发 |
| 步枪弹 | 0.02/发 |
| 霰弹 | 0.04/发 |
| 狙击弹 | 0.08/发 |
| 能量电池 | 0.03/发 |
| 榴弹 | 0.10/发 |
| 枪械整把 | 3–8 |
| 血包 | 1.5 |

**升级**：升级池新增 "+10 背包负重" 选项，加法叠加。

**背包可存物品**：子弹、枪械、血包。手雷不进背包（走现有 `grenades` 字典）。

### 4. 备弹槽

- 玩家身上 10 个槽位，每个槽可分配一种弹药类型
- 每槽容量 = 对应武器弹种的 `magazine_size`
- 换弹时消耗一个满槽填充弹匣
- 槽位打空后必须从背包补货

### 5. T 键操作

- 输入动作 `backpack`，绑定 T 键
- 按下打开全屏背包 UI（暂停，`PROCESS_MODE_WHEN_PAUSED`）
- 左侧列出背包物品（按类型分组），右侧展示 10 个备弹槽
- 点击/拖拽物品分配
- 关闭 UI 后进入 1.5s 实时的"整理"状态（可移动不可射击）

### 6. 警戒范围翻倍

同步决策：所有敌人感知参数全局 ×2（详见 CONTEXT.md "Chain Aggro" 条目）：
- awareness_range: 近战 8→16m, 远程 12→24m
- chase_range: 近战 25→50m, 远程 30→60m, 飞行 35→70m
- Alert 半径: 死亡 20→40m, 开枪 25→50m, 玩家开枪 30→60m

## 被否决的替代方案

### 保持金币单一货币
简单，但无法表达"子弹廉价"的语义——最低消费 1 金 = 24 发手枪弹，单发感觉贵。

### 十进制汇率（1金=10银=100铜）
层级太密，银币和金币边界模糊，武器和弹药可能挤在同一货币层级。

### 背包用格子上限
格子上限会限制"大量廉价子弹"的意图——99 个铜板买 99 发子弹却因为格子不够带不走，违背设计目标。

## 影响

- `run_director.gd`: `gold: int` → `copper: int`（内部统一铜），新增 `add_copper/spend_copper`，`gold_changed` 改为 `currency_changed`
- `shop_ui.gd`: AMMO_CONFIG 价格单位改为铜，GRENADE_CONFIG 改为银，武器价格改为金
- `hud.gd`: 金币显示改为金银铜混合格式
- `player.gd`: 新增 `backpack_weight/backpack_max_weight/ammo_slots`，新增 `action_backpack`
- 新建 `scripts/backpack_ui.gd` + `scenes/backpack_ui.tscn`
- `objects/monster_base.gd` / `monster_melee.gd` / `monster_ranged.gd` / `enemy.gd`：感知范围翻倍
- `alert_system.gd`：无需改动（alert 半径由调用方传入）
