# PRD：操作手感现代化提升

为当前基础骨架齐全但"肉"缺失的 FPS 操作手感补充现代化要素，让手感从"能用"变为"爽快"。

## 来源

- Grill 会话：`docs/adr/028-recoil-auto-recovery.md`（后坐力模型决策）
- 架构决策：`docs/adr/029-gamefeel-modernization.md`（整体设计系统）
- 领域词汇：`CONTEXT.md`「操作手感（Game Feel）」术语组

## 范围与优先级

**级别：B（中度扩展）** — 不动架构，修补核心痛点 + 引入简单新系统。

**优先级排序**：射击手感（A） > 移动手感（B） > 视听包装（C）

## 核心决策

### 后坐力模型（已裁定，ADR 028）

- **真实后坐 + 自动恢复**：相机角度确实被后坐力推开，停止射击后自动回弹
- **统一模板 + 参数差异化**：所有枪用同一套后坐逻辑，仅通过参数区分幅度
- 恢复参数：`recoil_recovery_speed`（默认 8.0）、`recoil_recovery_delay`（默认 0.08s）

### Grill 自行裁定的其余决策

| 决策项 | 选定方案 | 依据 |
|--------|----------|------|
| 动态准星 | 四线 procedural 准星，随移动/射击扩张，ADS 收紧 | 现代 FPS 标配，实现轻量 |
| 射击震屏 | Perlin-noise 相机抖动，按武器分振幅/频率，指数衰减 | 与近战震屏共用衰减模型 |
| 命中标记 | 小 × 形 UI + 短促"叮"音效，~200ms 淡出 | 简洁高效，不过度视觉污染 |
| 冲刺 | Hold Shift，1.6× 移速，FOV 75→85，冲刺中不可射击 | PvE 不需要体力条 |
| 蹲伏 | Hold Ctrl，0.5× 移速，碰撞体缩放降高 | 简单实用 |
| 武器摆动 | Procedural sine-wave：idle 呼吸慢摆 + move 节奏摆，ADS 减 70% | 无需动画资产 |
| 跳跃缓冲/土狼时间 | buffer=150ms, coyote=100ms | 行业标准值 |
| 换弹音效 | 每枪独立 `sound_reload` 字段 | 扩展 Weapon 资源 |
| 弹壳抛射 | GPUParticles3D 小方块，带重力自旋 | 简单但不简陋 |
| 受伤反馈 | 屏幕边缘红色 vignette + 方向指示箭头 | 与现有 Hit Flash 互补 |

## 不在 v1 范围

- 滑铲 / 翻越 / 墙壁跑（高级移动，C 级方案范围）
- 完整的骨骼 AnimationPlayer 驱动 viewmodel 动画（当前 Tween 足够）
- 空间音频混响系统（体量过大）
- 每枪独立 spray pattern（A 方案，不匹配 PvE Roguelike 定位）
- 手柄独立配置（v1 仅键盘鼠标）
