# T4 — 换弹机制（手动 + 空仓自动）

## 构建内容

按 R 手动换弹；弹匣归零继续扣扳机自动换弹；按 `reload_time` 将备弹转入弹匣；换弹中禁射；切枪取消换弹；备弹不足只装可用数；彻底空弹显示红色「空」。

## 验收标准

- [ ] 新增 `action_reload`，R 键和空仓射击触发
- [ ] 换弹期间 `reload_time` 计时，完成转移 reserve→magazine
- [ ] 换弹中射击被忽略；换弹中切枪取消换弹
- [ ] 备弹不足时只填充可用量；弹匣与备弹均 0 时 HUD 红字「空」
- [ ] 验收：空弹按 R 等待后补满；备弹耗尽后无法补满
