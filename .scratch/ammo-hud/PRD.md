# PRD：弹药 HUD 系统

为 FPS 项目新增弹匣+备弹弹药模型与右下角弹药 HUD（含换弹动作）。

## 来源

- 架构决策：`docs/adr/004-ammo-magazine-reserve.md`
- 领域词汇：CONTEXT.md「弹药系统」术语表

## 核心需求

1. 右下角显示弹药余量 HUD
2. 不同枪械显示不同（中文）名字
3. 能看到所有枪的剩余弹药
4. 简单的换弹动作（手动 R + 空仓自动 + 武器动画 + 进度条）

## 关键决策

- 弹药模型：弹匣（Magazine）+ 备弹（Reserve）两级
- 武器中文名：爆能枪 / 连发枪
- 弹药参数 per-weapon 独立配置：magazine_size、max_reserve、reload_time
- 换弹触发：R 键手动 + 空仓自动
- HUD 布局：右下角纵向列表，当前武器高亮，其余半透明灰
- 换弹动作：机制 + 武器 Tween 动画 + HUD 进度条
- 边界：换弹中禁射、切枪取消换弹、空弹红字、备弹不足只装可用数
- 显示格式：`武器名 弹匣 / 备弹`
