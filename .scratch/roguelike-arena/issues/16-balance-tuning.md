# 16 — 平衡调优 + 手感打磨

Status: planning
Type: task
Refs: ADR 022, issues 09–15

## 描述

全部敌人和武器上线后的数值调优与手感打磨。所有参数均为 `@export` 可变，本工单不做新功能、只调数值。

## 前置依赖

- [ ] issue 09–15 全部完成

## 验收标准

### 敌人平衡

- [ ] 波次 1–3 新玩家能无压力清普通女/普通黑女/游戏宅
- [ ] 波次 10 时有适度压力（健壮男/机器人入场）
- [ ] 波次 15+ 难以存活（驯兽师/忍者入场），但高手能撑
- [ ] 各敌人 `health` / `move_speed` / `attack_damage` / `attack_cooldown` 调整到合理
- [ ] 光环类敌人叠加时不会出现极值（如 3 个日本艺妓加速不让敌人瞬移）

### 武器平衡

- [ ] 每种弹种有清晰的定位（ADR 022 武器身份表）：
  - 手枪弹：廉价通用（1 金/捆），伤害偏低，前期主力
  - 步枪弹：中程主力（2 金/捆），性价比最高，中后期泛用
  - 霰弹：近身爆发（3 金/捆），高风险高回报
  - 狙击弹：远程点杀（4 金/捆），最贵，弹药稀缺
  - 能量电池：精准持续（3 金/捆），中远程精准，无弹道下坠
  - 榴弹：AOE 清群（5 金/捆），最贵，弹药极少
- [ ] 武器价格与强度正相关（贵枪明显强但不碾压）
- [ ] 每把枪的定位和可靠性评级（★）在实战中可感知：
  - ★★★ 级（耐久 ≥200）：初始手枪(200)、SMG(240)、双枪口SMG(210)、机枪(280)、持续射线枪(220)——可靠主力
  - ★☆☆ 级（耐久 ≤85）：4管喷(70)、重型喷(85)、狙击(50)、重型狙击(35)、榴弹(25)——爆发神器，每发都是决策
  - ★★☆ 级（耐久 86–199）：其余 8 把——正常消耗品
- [ ] 商店出现频率合适（不要玩家全程只看到手枪）

### 弹药经济

- [ ] 初始手枪弹 36 + 弹匣 12 = 48 发足够清前 2 波（约 6–10 只普通小怪）
- [ ] 金币收入（击杀奖励：5–25 金/怪）+ 弹药价格比例合理：最低廉弹药捆仅 1 金，击杀最弱怪即可买 24 发手枪弹——弹药永不"软锁"
- [ ] 高稀有度弹种（狙击 4 金、榴弹 5 金）需策略性购买，不可无脑挥霍
- [ ] 宝箱武器掉落不会让玩家跳过经济系统（价格参照商店价 × 波次系数）

### 耐久度平衡

- [ ] 各枪耐久度衰减速度合理（连续开火可持续时间指标）：
  - 手枪 200 发 / 60s 连射 → 不换能撑 3–4 波
  - SMG 240 发 / 29s 连射 → 不换撑 2–3 波（但开火时间短）
  - 机枪 280 发 / 22s 连射 → 火力最猛但寿命最短，1.5–2 波
  - 狙击 50 发 / 60s 连射 → 按精英节奏能用 3–4 波
  - 重型狙击 35 发 → 最极端的"每发都是决策"，1.5–2 波（用得好则更久）
- [ ] 激励多枪轮换——玩家被迫在"继续用残枪"和"爆掉前换新枪"之间决策
- [ ] 爆掉频率不过高（不至于每波都爆）也不过低（不能一把枪通关）
- [ ] 弹药成本作为隐形平衡杠杆生效：机枪 1.25g/s 烧弹药 → 即使用了不爆，弹药费也逼迫控制开火
- [ ] 同枪重复持有策略验证（如 3 把 SMG 轮换是否过于强势——靠耐久衰减 + 弹药消耗自然平衡）

### 手雷平衡

- [ ] EMP 沉默/减速时长不过度——敌人 3s 后恢复，不无限控
- [ ] 破片伤害 40 不能秒杀大部分敌人——AOE 补刀型而非主力
- [ ] 手雷获取频率（商店刷新率 + 宝箱掉率）合理，25/20 金定价与弹药经济匹配

### 测试

- [ ] `tests/test_balance_wave_survival.gd`：模拟脚本跑 20 波，统计玩家死亡波次中位数在 12–16 之间
- [ ] `tests/test_balance_ammo_economy.gd`：模拟 5 波内的金币/弹药/耐久流入流出，验证不出现"软锁"（没钱没弹没可用枪）
