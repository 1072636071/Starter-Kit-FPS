## 验收标准

### 1. 消除重复武器目录扫描

`shop_ui.gd` 和 `run_director.gd` 各有一份几乎相同的 `res://weapons/` 目录 `.tres` 扫描逻辑（`DirAccess.open` → `list_dir_begin` → 遍历过滤 → `load`）。

- [ ] 提取共享方法，例如 `WeaponPool` autoload 或 `scripts/weapon_utils.gd` 静态类中的 `static func load_all_weapons() -> Array[Weapon]`
- [ ] `shop_ui.gd` 和 `run_director.gd` 改为调用共享方法
- [ ] 扫描结果可按需缓存（本局不变）

### 2. 收敛手雷系统（散弹式修改）

手雷系统当前跨越 `player.gd`（输入/状态/投掷）、`hud.gd`（UI 显示）、`shop_ui.gd`（购买）、`run_director.gd`（宝箱补给）四个文件。

- [ ] 评估是否将手雷逻辑集中到 `GrenadeManager` autoload 或 `player.gd` 内部专用类
- [ ] 至少：定义手雷类型 enum（`enum GrenadeType { EMP, FRAG }`），替代散落的 `&"emp"`/`&"frag"` 字符串键
- [ ] 手雷相关的常量和辅助方法（`GRENADE_MIN_SPEED`、`GRENADE_CHARGE_MAX`、数量校验）收敛到单一位置

### 3. 消除手雷字符串键原始类型偏执

`grenades` Dictionary 键使用字符串字面量 `&"emp"`/`&"frag"`，散布于 `player.gd`、`hud.gd`、`shop_ui.gd`、`run_director.gd` 多处。拼写错误无编译期检查。

- [ ] 定义 `enum GrenadeType { EMP, FRAG }`，或小型资源类
- [ ] 将 `grenades: Dictionary` 改为 `grenades: Dictionary[GrenadeType, int]`（若 GDScript 支持 enum 键）或使用 `grenade_emp: int` / `grenade_frag: int` 独立字段
- [ ] 所有引用字符串键的代码改为引用 enum 常量

### 4. hud.gd 按职责拆分（发散式变更）

`hud.gd` 当前承载：弹药列表、护盾条、波次提示、宝箱提示、卡住提示、手雷显示、武器检视 UI。每次新增功能追加 ~50 行。

- [ ] 将手雷 HUD 逻辑提取到 `scripts/grenade_hud.gd`（`hud.gd` 托管实例）
- [ ] 将耐久 HUD 逻辑提取到 `scripts/durability_hud.gd`（或合并入现有弹药列表逻辑）
- [ ] `hud.gd` 保留顶层协调（信号绑定、布局），子模块各自管理自己的 UI 子树

### 5. 消除商店按钮状态刷新的消息链

`shop_ui.gd` 的 `_refresh_all_button_states()` 遍历三层嵌套（zone → row → child），通过 Label 文本匹配（`"金" in c.text`）定位价格标签，脆弱且难以维护。

- [ ] 在构建购买行时存储结构化引用（例如 `row_data: Dictionary = {"price_label": Label, "buy_btn": Button, "price": int}`）
- [ ] `_refresh_all_button_states()` 改为遍历结构化引用数组而非运行时文本解析
- [ ] 移除 `child.name == "BuyAmmoBtn"` / `"金" in c.text` 等启发式搜索

### 6. 统一爆枪方法命名

Issue 20 spec 要求方法名为 `_break_weapon(slot)`，实现为 `_on_weapon_broken(index)`。

- [ ] 重命名为 `_break_weapon(index)` 以匹配 spec
- [ ] 全项目搜索 `_on_weapon_broken` 引用并同步更新

### 7. 宝箱随机武器去重（可选）

Issue 24 spec L30 标记为可选优化（v1 可略）：不抽玩家已装备的同款枪。

- [ ] `run_director.gd` 的 `_apply_random_weapon_reward()` 在加权抽选前过滤掉 `_player.weapons` 中已持有的同款 Weapon 资源
- [ ] 若全部已持有 → 降级为金币补偿
