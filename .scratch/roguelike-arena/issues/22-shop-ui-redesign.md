# 22 — 商店 UI 三区重构（武器 / 弹药 / 手雷）

Status: done
Type: task
Refs: ADR 022, issues 04/09/19

## 描述

将现有单区商店 UI 重构为三区布局（武器区 / 弹药区 / 手雷区），接入弹药池和新武器系统。

## 前置依赖

- [ ] issue 04（商店物理摊位 + 基础 UI 框架）
- [x] issue 09（`Weapon.ammo_type` / `weapon_cost` 字段）
- [ ] issue 19（`.tres` 文件存在，含全部武器参数）
- [ ] issue 21（`ammo_reserve` 字典存在）

## 验收标准

### 武器区

- [ ] 从 20 把枪池中随机抽 3 把不重复武器展示
- [ ] 每把展示：3D 模型预览（`SubViewport` 内小相机渲染）+ 名称 + 价格 + 弹药类型图标 + 耐久度条
- [ ] 有空槽 → 显示"购买"按钮（`spend_gold(weapon_cost)` → 装填到第一空槽，耐久满）
- [ ] 3 槽全满 → 显示"购买并替换"按钮 → 弹出 3 槽选择对话框（显示各槽当前武器名）→ 确认后替换
- [ ] 替换时旧武器不掉落（直接消失），新武器满耐久

### 弹药区

- [ ] 从 6 种弹药中随机抽 3–4 种不重复展示
- [ ] 显示：弹药名 + 捆图标 + 捆量 + 价格（金）+ 当前储备量
- [ ] 价格表（ADR 022）：
  - 手枪弹捆 24 发 / 1 金
  - 步枪弹捆 20 / 2 金
  - 霰弹捆 8 / 3 金
  - 狙击弹捆 4 / 4 金
  - 能量电池捆 12 / 3 金
  - 榴弹捆 2 / 5 金
- [ ] 购买 → `ammo_reserve[type] += bundle_amount`，金币扣减，UI 即时刷新

### 手雷区

- [ ] 随机展示 1–2 种手雷（EMP / 破片）
- [ ] EMP 25 金 / 破片 20 金
- [ ] 购买 → `grenades[type] += 1`（不超过 `max_grenades = 5`）

### UI 要求

- [ ] `PROCESS_MODE_WHEN_PAUSED`
- [ ] 金币余额实时显示在顶部
- [ ] 购买确认弹窗（防误触）
- [ ] ESC 关闭商店（已有逻辑，确认兼容三区）

### 测试

- [ ] `tests/test_shop_ui_redesign.gd`：
  - 打开商店 → 断言武器区有 3 把不重复枪、弹药区有 3–4 种不重复弹种
  - 购买手枪弹捆 → 断言 `ammo_reserve["手枪弹"]` 增加 24
  - 满槽买枪 → 断言替换对话框弹出、确认后旧枪消失新枪入槽
