# 27 — 平衡调优 + 手感打磨

Status: ready-for-agent
Type: task
Refs: ADR 022, issues 10–26

## 描述

全部敌人和武器上线后的数值调优与手感打磨。所有参数均为 `@export` 可变，本工单不做新功能、只调数值。

## 前置依赖

- [ ] issue 10–26 全部完成

## 验收标准

### 敌人平衡

- [ ] 波次 1–3 新玩家能无压力清普通女/普通黑女/游戏宅
- [ ] 波次 10 时有适度压力（健壮男/机器人入场）
- [ ] 波次 15+ 难以存活（驯兽师/忍者入场），但高手能撑
- [ ] 各敌人 `health` / `move_speed` / `attack_damage` / `attack_cooldown` 调整到合理
- [ ] 光环类敌人叠加时不会出现极值（如 3 个日本艺妓加速不让敌人瞬移）

### 武器平衡

- [ ] 每种弹种有清晰的定位：
  - 手枪弹：廉价通用（1 金/24 发），伤害偏低，前期主力
  - 步枪弹：中程主力（2 金/20 发），性价比最高
  - 霰弹：近身爆发（3 金/8 发），高风险高回报
  - 狙击弹：远程点杀（4 金/4 发），最贵，弹药稀缺
  - 能量电池：精准持续（3 金/12 发），无弹道下坠
  - 榴弹：AOE 清群（5 金/2 发），弹药极少
- [ ] 武器价格与强度正相关（贵枪明显强但不碾压）
- [ ] 可靠性 ★ 星级在实战中可感知
- [ ] 商店出现频率合适

### 弹药经济

- [ ] 初始手枪弹 36 + 弹匣 12 = 48 发足够清前 2 波
- [ ] 金币收入 + 弹药价格比例合理：最低廉弹药捆仅 1 金
- [ ] 高稀有度弹种需策略性购买
- [ ] 宝箱武器掉落不会让玩家跳过经济系统

### 耐久度平衡

- [ ] 各枪连射可持续时间指标合理
- [ ] 激励多枪轮换——"继续用残枪" vs "爆掉前换新枪"
- [ ] 爆掉频率适中（不至每波都爆、不至一把枪通关）
- [ ] 弹药成本作为隐形平衡杠杆生效

### 手雷平衡

- [ ] EMP 沉默/减速时长不过度
- [ ] 破片伤害 40 不能秒杀大部分敌人
- [ ] 手雷获取频率合理，定价与弹药经济匹配

### 测试

- [ ] `tests/test_balance_wave_survival.gd`：模拟脚本跑 20 波，统计玩家死亡波次中位数在 12–16 之间
- [ ] `tests/test_balance_ammo_economy.gd`：模拟 5 波内的金币/弹药/耐久流入流出，验证不软锁
