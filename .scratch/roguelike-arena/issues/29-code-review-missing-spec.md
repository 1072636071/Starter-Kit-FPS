## 验收标准

### 1. Beam 武器耐久扣减（issue 20）

spec L27-28 要求持续射线枪按 `tick_interval` 在 `_process` 中减耐久。当前完全无 beam 模式处理。

- [ ] `player.gd` 开火逻辑中检测 `weapon_mode == "beam"`，在 `_process` 中按 `tick_interval`（如 1s）调用耐久扣减
- [ ] beam 模式下每次 tick 减 1 耐久（与离散弹体一次射击减 1 同语义）

### 2. 手雷抛物线预览（issue 23）

spec L20-21 要求蓄力时显示抛物线预览（白色点线）。

- [ ] 新建或复用抛物线绘制工具（LineRenderer / MeshInstance3D 点线，白色）
- [ ] G 键按住蓄力时，实时绘制从相机到预估落点的抛物线
- [ ] 随蓄力时间增长，预览落点变远（反映蓄力速度插值）
- [ ] 释放 G 或取消蓄力时清除预览线

### 3. 商店 3D 武器模型预览（issue 22）

spec L23 要求武器区展示 "3D 模型预览（SubViewport 内小相机渲染）+ 弹药类型图标"。

- [ ] 每把商店武器行内嵌 `SubViewport` + 小 `Camera3D`，渲染该武器的 3D 模型（layer 单独控制）
- [ ] 弹药类型图标（6 种弹种各一 icon 或 emoji 替代）
- [ ] 无 `SubViewport` 时至少用图标区分弹种（替代方案）

### 4. 弹药耗尽提示（issue 21）

spec L26 要求弹药归零时 "无法射击 + 无法换弹，显示提示'弹药耗尽'"。

- [ ] 扣扳机时若 `ammo_reserve[type] <= 0` 且弹匣也为 0，在屏幕中央显示 "弹药耗尽" 提示（1.5s 淡出）
- [ ] 换弹时若对应弹药池为 0，同样显示提示

### 5. 宝箱满槽替换对话框（issue 24）

spec L29 要求满槽随机武器 "弹出替换对话框（复用商店替换 UI 逻辑）"。当前直接 `add_gold(30)` 补偿。

- [ ] `run_director.gd` 的 `_apply_random_weapon_reward()` 满槽分支改为弹出替换对话框
- [ ] 复用商店 `shop_ui.gd` 的替换弹窗逻辑（或提取共享方法）
- [ ] 确认后替换旧枪，拒绝则回退（不给金币补偿）

### 6. HUD 耐久条动态宽度（issue 20）

spec L44-45 要求耐久条宽 "同武器名"。当前固定 `Vector2(120, 4)`。

- [ ] 耐久条宽度从对应 `name_label` 的 `get_rect().size.x` 动态获取
- [ ] 若 name_label 宽度随武器名变化（如中英文武器名），耐久条同步

### 7. 手雷切换支持滚轮（issue 23）

spec L23 要求 "按住 G + 滚轮/caps → 切换手雷类型"。当前 `grenade_switch` 仅绑了 `physical_keycode=4194306`（疑似 CapsLock），无滚轮。

- [ ] `project.godot` 的 `grenade_switch` 动作追加鼠标滚轮上下事件
- [ ] 滚轮向上切 EMP、向下切破片（或循环切换）

### 8. ammo_reserve_changed 信号（issue 21）

spec L24-25 要求 `ammo_reserve` 变更时 emit `ammo_reserve_changed(dict)` 信号。当前仍用旧 `ammo_updated` 传数组快照。

- [ ] `player.gd` 新增 `signal ammo_reserve_changed(reserve: Dictionary)`
- [ ] 所有修改 `ammo_reserve` 的位置（开火/换弹/商店购买/宝箱补给）统一 emit 此信号
- [ ] HUD 监听新信号以刷新弹药显示（可与旧信号共存过渡）
