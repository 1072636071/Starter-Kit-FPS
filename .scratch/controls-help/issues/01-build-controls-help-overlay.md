# 构建按键说明面板

**Status:** resolved

**Blocked by:** 无 — 可立即开始

**构建内容：** 按 F5 → 游戏暂停、鼠标可见 → 分组键位说明模态面板弹出（移动 / 射击 / 战斗 / 系统 / 经济）→ 再按 F5 或点击背景关闭 → 游戏恢复、鼠标捕获。端到端可演示。

**验收标准：**

- [ ] 新增 `controls_help` 输入动作，绑定 F5
- [ ] F5 按下时游戏暂停（`get_tree().paused = true`）、鼠标切到 `MOUSE_MODE_VISIBLE`
- [ ] 面板以暗色背景 + 居中分组列表展示约 20 条操作键位，中文标签从映射字典读取，键名从 InputMap 动态获取
- [ ] 面板内容按移动 / 射击 / 战斗 / 系统 / 经济分类展示
- [ ] 再按 F5 关闭面板，游戏恢复（`get_tree().paused = false`）、鼠标恢复 `MOUSE_MODE_CAPTURED`
- [ ] 点击面板外暗色背景也可关闭面板
- [ ] 已被其他暂停源（商店/升级/死亡）暂停时 F5 无效（门控 `paused == false`）
- [ ] 打开面板期间若触发更高优先级暂停源（如死亡），面板被接管并隐藏
- [ ] 面板为第 4 个暂停源，遵循 ADR 015 暂停互斥规则
