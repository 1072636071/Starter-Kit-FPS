# 04 — 出生点与商店位置适配新地图

Status: ready-for-agent

## 父 issue

`.scratch/arena-fixes/PRD.md`

## 构建内容

按 F 开波后，怪物从城市内多个方向的道路上刷出，站在有效地面上不会坠落。商店摊位位于城市内可达区域，玩家能正常走入购买弹药。

## 验收标准

- [ ] `main.tscn` 中 8 个 SpawnPoints（Marker3D）全部位于新城市地图有瓦片覆盖的区域内
- [ ] 出生点分布在城市四角和边缘道路上（多方向来袭）
- [ ] 出生点 y 坐标为 0.5（略高于地面，避免卡地板）
- [ ] 出生点所在 cell 为道路或人行道（structure 0-6），不在建筑内
- [ ] ShopStation 位置调整到城市内可达区域（道路上或广场旁）
- [ ] 运行游戏，按 F 开波后怪物出现在城市内、站在道路上、正常追踪玩家
- [ ] 怪物不会在出生点坠落或卡在建筑内
- [ ] 玩家可以正常走到商店摊位触发购买 UI
