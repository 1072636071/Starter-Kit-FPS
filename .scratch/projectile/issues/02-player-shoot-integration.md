# 02 - 玩家射击集成弹体

Status: resolved
Type: task

## 构建内容

玩家射击时，每发子弹从枪口生成弹体并飞向命中点；两把现有武器（blaster、blaster-repeater）配置各自的弹体外观。完成后，运行游戏射击即可看到弹体飞行效果。

## 验收标准

- [ ] 玩家射击时，每次 RayCast 命中均从枪口位置生成弹体
- [ ] 弹体沿 RayCast 方向飞向碰撞点，到达后销毁
- [ ] 弹体颜色、大小、速度读取当前武器配置
- [ ] blaster 武器配置弹体属性（如橙色、较大、速度 100）
- [ ] blaster-repeater 武器配置弹体属性（如蓝色、较小、速度 120）
- [ ] 运行游戏射击时弹体飞行效果自然，无明显延迟或穿帮
