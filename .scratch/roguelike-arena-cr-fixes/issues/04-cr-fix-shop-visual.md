# 04 — 商店视觉补全（模型预览 + 弹药捆图标）

**Status:** done

**Blocked by:** 无——可立即开始

**构建内容：** 商店 UI 视觉层面的两项补全：武器区每把枪显示 3D 模型预览（小旋转展示），弹药区每种弹种显示捆图标——让商店信息更直观，与 issue 22 spec 对齐。

**验收标准：**

### 武器 3D 模型预览

- [ ] 武器区每行嵌入 `SubViewport`，内放小 `Camera3D` 渲染该枪的 3D 模型
- [ ] 模型缓慢自动旋转（绕 Y 轴），让玩家看清武器外观
- [ ] SubViewport 尺寸适中（约 80×60 px），不挤占名称/价格/耐久信息空间
- [ ] 渲染层隔离（layer 2 或专属 layer），不进入主相机视野

### 弹药捆图标

- [ ] 弹药区每行左侧或名称旁添加捆图标——用简单几何体或 Unicode 符号区分 6 种弹种
- [ ] 图标与弹种一一对应（如手枪弹=圆点、步枪弹=菱形、霰弹=三点、狙击弹=细长条、能量电池=闪电、榴弹=爆炸星形）
- [ ] 图标不占用过多水平空间，当前布局中自然嵌入
