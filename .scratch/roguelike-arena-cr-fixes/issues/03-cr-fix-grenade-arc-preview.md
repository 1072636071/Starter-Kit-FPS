# 03 — 手雷抛物线预览

**Status:** done

**Blocked by:** 02

**构建内容：** 玩家按 G 蓄力投掷手雷时，屏幕中显示白色点线抛物线预览，蓄力越久弧线越远，释放后预览消失。给玩家投掷距离的直观反馈。

**验收标准：**

- [ ] 蓄力开始时（`is_charging_grenade == true`），在相机前方显示抛物线预览
- [ ] 预览形态：白色点线（`LineRenderer` 或 `MeshInstance3D` 离散点），沿抛物线路径采样
- [ ] 预览长度随 `grenade_charge_time` 实时变化：蓄力越久，预览弧线越远
- [ ] 抛物线计算使用当前投掷参数（`throw_dir`、`throw_speed`、重力加速度）
- [ ] 释放 G 投掷后预览立即隐藏
- [ ] 预览不受暂停影响（或随游戏暂停一起冻结——两种均可，注明决策）
- [ ] 预览仅在玩家可见层（layer 2 或独立 viewport），不泄漏进主世界
